# fzf-mc

Midnight Commander inspired terminal file manager built around fzf.

## Goals

- Dual panel workflow
- fzf based navigation
- Termux compatibility
- SSH and remote backends
- rclone support
- Plugin architecture

## Status

Early alpha development.
